Projects

CloudDrive: Serverless Cloud Storage

Personal project. Frontend runs locally during development.

A file storage app with a React and Vite frontend and a serverless AWS backend. Users sign in, upload files directly to S3, list their files and delete them.

  • Authentication through Amazon Cognito (hosted UI, OIDC).
  • Uploads use S3 pre-signed URLs, so files go straight to S3 instead of through the API. This avoids API Gateway payload limits.
  • Three AWS Lambda functions (Node.js) handle upload URL generation, file listing and deletion, with file metadata stored in DynamoDB.
  • Each user's files are kept under their own S3 prefix and filtered per user in the database.
  • Known trade-off: the listing function uses a DynamoDB Scan. A larger version would use a Query on a global secondary index.

ESP32 Sound Detector Band for Hearing-Impaired Users

Assistive IoT prototype. Documented in a project report.

An ESP32-based wearable concept that detects sounds in the environment and alerts the wearer through vibration, so people who are deaf or hard of hearing can notice important sounds around them.

  • Approach: microphone or sound sensor input, threshold-based sound detection on an ESP32, and a vibration motor for feedback.
  • Circuit design and simulation with Proteus.
  • The GitHub repository currently contains the project report (PDF) and a short README. Firmware source code is not published there yet.
  • ESP32
  • Sound sensor
  • Vibration motor
  • Embedded
  • Proteus
